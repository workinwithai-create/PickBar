# PickBar

Anacrusis desk for bedroom producers and AI-music finishers.

Suno and loop DAWs start on the one. Session players write the notes that live *before* that one: bass 5, walk-up, nylon lick, flam, grace, open hat, brass door, violin lead, tom fill, rest door. PickBar seats those pickups on the and-of-4 of every bar so the next chord has a door.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and an acoustic kit (kick, snare, hi-hat, crash, tom1, tom2, tom3). Pinned to PreEight commit `d58301e4a494555f411a2afbc448b724136eee76`. No `@main`. No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the rest of the line

Yesterday's ship was TagFour (four bars *after* the last chorus, then silence). PickBar is the bar *before* the one.

| Tool | Job |
| --- | --- |
| TagFour | Four-bar last-line tag after the money chorus |
| LiftTwo | Two-bar production lift into the hook |
| PreEight | Eight-bar musical pre-chorus |
| AfterHook | Eight bars after the hook |
| EndEight | Last eight bars of the record |
| LastHook | Last chorus, not a photocopy |
| ModEight | Modal color change inside eight bars |
| OpenEight | First eight bars of the record itself |
| **PickBar** | The anacrusis — pickups on the and-of-4 so the one is not cold |
